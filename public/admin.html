GitHub prepojenie

Na publikovanie zmien zo správy je potrebný GitHub token (fine-grained PAT) s právom Contents: Read & Write len pre tento repozitár. Token sa ukladá zašifrovaný (AES-GCM) kľúčom odvodeným z vášho hesla.

Bezpečnosť

Toto je statická stránka — prihlásenie chráni rozhranie a zašifrovaný token, údaje farností sú verejné. Pre serverovú ochranu admin stránky odporúčame zapnúť Cloudflare Access na ceste /admin.html (návod v README). Heslo zmeníte príkazom node scripts/hash-password.mjs a nasadením nového odtlačku.
